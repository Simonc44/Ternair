# Code de Conduite de la Communaut Ternair

Notre engagement : faire de la participation a Ternair une experience
sans harclement, ouverte et accueillante pour tout le monde, quel que
soit le genre, l'orientation sexuelle, le handicap, l'apparence
physique, la taille, l'origine ethnique, la nationalite, l'age, la
religion, le niveau d'experience technique ou le statut socio-
economique.

---

## 1. Comportements attendus

- Faire preuve de bienveillance et d'empathie envers les autres.
- Respecter les opinions, points de vue et experiences differents.
- Donner et accepter gracieusement les retours constructifs.
- Se concentrer sur ce qui est le mieux pour la communaute et le
  projet.
- Faire preuve de patience face aux debutants : nous avons tous ete
  nouveaux un jour.

## 2. Comportements inacceptables

- Harclement verbal, sexuel ou autre, sous quelque forme que ce soit.
  Inclut les images sexualisees, le langage degrade, les intimidations
  et les poursuites.
- Commentaires insultants ou discriminatoires (racistes, sexistes,
  homophobes, validistes, transphobes, etc.).
- Publication d'informations privees d'autrui sans permission
  explicite (doxxing).
- Spam, autopromotion excessive ou hors sujet.
- Conduite perturbatrice en reunion, salon Discord, issues ou PR.

## 3. Responsabilites des mainteneurs

Les mainteneurs du projet sont responsables de clarifier les standards
de conduite et de prendre les actions correctives appropriees en
reponse a tout comportement inacceptable.

Ils peuvent :
- Supprimer, editer ou rejeter commentaires, commits, code, issues,
  PR et toute autre contribution non alignee avec ce code de conduite.
- Bannir temporairement ou definitivement tout contributeur pour des
  comportements juges inappropries, menaçants, offensants ou blessants.

## 4. Application

En cas de comportement inacceptable, ouvrez une issue privee
(`[conduite]` en prefixe) ou contactez un mainteneur directement par
email. Toutes les plaintes seront examinees promptement et de
maniere equitable.

Les mainteneurs s'engagent a :
1. Traiter chaque signalement de maniere confidentielle.
2. Ne pas reveler l'identite du plaignant sans son accord.
3. Publier un resume de l'incident et de la sanction pour
   transparence (avec pseudonyme si necessaire).

## 5. Portee

Ce code de conduite s'applique dans tous les espaces du projet :
- Le depot GitHub (issues, PR, discussions, code reviews).
- Les salons communautaires (Discord, Matrix, listes de diffusion).
- Les evenements en ligne ou en personne organises sous la marque
  Ternair.
- Les representations publiques du projet sur les reseaux sociaux.

## 6. Inspiration

Ce code est largement inspire du
[Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
adapte au contexte de Ternair (projet de recherche en IA,
communaut principalement francophone et anglophone, taille moyenne).
