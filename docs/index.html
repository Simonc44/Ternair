Ternair loads Microsoft's BitNet b1.58 models — including the real 2B-4T — and serves them behind an OpenAI-compatible API. 4× smaller files, pure Python, no C++ build.

# Install
pip install ternair

# Serve a real BitNet model
ternair serve --model microsoft/bitnet-b1.58-2B-4T --port 8080

How it works

Three commands. That's it.

1

Install

pip install ternair

Pure Python. No C++ compiler. No CUDA toolkit. Just pip.

→
2

Convert

ternair import-bitnet --source ./bitnet-2b4t --output ./ternair-2b4t

Bit-exact conversion. Same trained weights. 4× smaller file.

→
3

Serve

ternair serve --model ./ternair-2b4t --port 8080

OpenAI-compatible API. Ready for your app.

Everything you need

⚡

Ternary Weights

{-1, 0, +1} weights with per-row absmean quantization. Same recipe as BitNet b1.58.

📦

Packed Storage

Base-3 codec: 5 trits/byte (1.6 bits/value). 20% smaller than standard 2-bit packing.

🚀

KV-Cache Inference

Prefill once, decode one token per step. Correct RoPE position offsets. Streaming generation.

🌐

OpenAI API Server

/v1/completions, /v1/chat/completions, /v1/batch, /metrics. Zero external dependencies.

🔧

Multiple Backends

PyTorch (always works), NumPy, Triton GPU, C++ CPU. Automatic fallback per device.

📊

Prometheus Metrics

Requests, tokens/s, latency percentiles. Ready for production monitoring.

Get started in 30 seconds

terminal 
# Install Ternair
pip install ternair

# Quick test with a tiny model
ternair demo

# Download and serve the real 2B-4T model
hf download microsoft/bitnet-b1.58-2B-4T --local-dir ./bitnet-2b4t
ternair import-bitnet --source ./bitnet-2b4t --output ./ternair-2b4t --storage packed
ternair serve --model ./ternair-2b4t --port 8080
